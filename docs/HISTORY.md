# 实验历史摘要

本文件只保留影响当前决策的结果。详细中间模型、逐回合评估和失败实现已
删除，必要时可从 Git 历史恢复已跟踪内容。

## 经典参数

- low：20 m/s、60 m / 0.7，真实 10/10；
- mid：25 m/s，真实 10/10；
- high：30 m/s、15 m / 2.0，历史最好 5/10；
- High 短预测、35 m/s、末制导增益 3.0 均未改善，约 2--3/10。

## 已拒绝的方法

| 方法 | 大致结果 | 决策 |
| --- | --- | --- |
| MAPPO residual v1 | 离线 100 局约 `+0.14/局`，波动覆盖收益 | 删除 |
| MAPPO deadline-off 重训 | 独立 50 局约 `-0.30 ± 0.15` | 删除 |
| IMM + APN v1 | 离线明显提升；同 seed 实机 classic 5、APN 3 | 删除 |
| APN v2 / truth APN | 离线环境与实机命中不一致 | 删除 |
| IMM + 小型 GRU | 单一真实日志回放与 IMM 基本持平 | 删除 |
| High deadline | deadline-off 离线约 `+0.16/局` | 保留修正，不再单独扩展 |

这些结果共同说明：当前仿真对 High 末端命中的绝对数不可信，复杂模型的
小幅离线收益不值得增加比赛代码和部署风险。

## 保留的 LOS-PN 证据

- 选参窗口比较：`6/4 s` 优于 `5/3 s`、`4/2.5 s`；
- 独立 100 局：classic `0.41`，LOS-PN `3.40`，增量
  `+2.99 ± 0.19`；
- 10 局诊断：候选窗口平均 LOS rate 从 `0.304` 降至
  `0.275 rad/s`；
- 构造运行输入 P95：classic 约 `5.15 ms`，LOS-PN 约 `8.28 ms`。

因此 LOS-PN 是唯一保留的 High 候选，但是否采用只由真实平台配对结果
决定。2026-07-27 首组正式平台同 seed A/B 为 classic 3/10、LOS-PN
5/10。随后 LOS-PN 在 5 个预先随机固定的新 seed 上得到
`8、7、7、5、7`，平均 `6.8/10`；证明绝对表现较稳定，但这五局没有
对应的 classic 配对。
